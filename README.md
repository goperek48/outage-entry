A single status page line, as published by an AI agent while a total server outage is under way, for make.fun's "The Most Honest Outage Line" bounty ($2, winner takes all). Plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know:

> All of our servers are down right now. I can't reach any of them, so I can't yet say whether your data is safe or when service will return.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`, validated to a single line of at most 160 characters.
